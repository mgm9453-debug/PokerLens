# 視覺辨識介面

目前已接入八人桌樣式的牌面字形、花色、原生文字辨識、下注區與持牌紅色及綠色牌背辨識。金額目前需使用籌碼數字顯示，大盲倍數模式尚未支援。
背景執行緒確認連續三幀後組裝牌局；底池、全部座位下注、跟注差額、持牌人數及底牌不足時，不輸出完整分析。各數據可獨立顯示已讀值。自動流程直接讀指定視窗圖形內容，桌面遮擋不再使擷取暫停；最小化、黑畫面、視窗關閉及超過兩秒沒有新影格仍會暫停。擷取失敗時重新建立來源，舊工作階段回呼不得污染新影格。
原生文字辨識不提供機率信心；使用多幀、區域背景、籌碼存在證據與金額一致性驗證，不能把缺字當零。未知對手籌碼使用明確旗標，不當成實際零籌碼。
牌型、權益及決策只由已確認資料計算。其他桌型尚未驗證；沒有遊戲操作或自動下注。
