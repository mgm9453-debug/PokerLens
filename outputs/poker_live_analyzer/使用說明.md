# PokerLens 使用說明

此版本支援六人及八人桌樣式的自動牌面、金額及持牌人數辨識；啟動後自動追蹤牌桌，不需要按「分析」。

## 手動框選與固定位置辨識

固定位置適合修正底池、跟注額或特定座位反覆定位失敗。先開啟牌桌，保持籌碼數字顯示，並將對手牌背設成綠色。

1. 開啟「調整設定 → 辨識位置 → 框選與校準辨識位置」，選擇牌桌與六人／八人版型，按「更新預覽」。
2. 在右側選擇需要修正的欄位，再於左側定格預覽拖曳框選。金額框住完整數字；牌面框住整排完整牌；牌背框住綠色牌背。未框選的欄位繼續使用原本定位。
3. 按「驗證讀取」，檢查右側逐欄結果。通過後按「鎖定並儲存」，正在運行的自動辨識會重新讀取並套用；之後啟動也會載入。

可框選自身底牌、公共牌、底池、跟注金額、自身籌碼，以及各座位籌碼、下注與牌背。預覽採指定視窗內容擷取，可被其他視窗遮擋；牌桌不能最小化，遊戲內的視窗或動畫仍可能遮住數字。

自身為座位零；其他座位從左下往上依序為一、二、三、四，再往右依序為五、六、七。六人桌略過二、六。選擇座位欄位時，介面會提示左上、右下等位置。

自訂下注框若要確認「沒有下注」，請一併框選該座位下注金額上方的籌碼圖示區。只有文字與籌碼證據都清楚時，才接受空白代表零；未知金額會保留未知。座位籌碼用於讀取籌碼，當手持牌狀態仍由綠色牌背判斷。

驗證需要連續三個新影格讀取一致。底牌驗證需等發出兩張牌；金額正在變動時，等待動畫結束後再試。失敗結果會指出需要重新框選的欄位。

位置以牌桌內的比例儲存，等比例放大或縮小時同步調整。長寬比例改變超過百分之三會暫停並要求重新校準；版型、牌桌外觀或文字位置改變時，也應重新驗證。要調整已鎖定位置，按「重新校準」；要停用所有自訂位置，按「使用自動定位」。未驗證、未鎖定的草稿不會套用到即時分析。

校準設定保存於 `%LOCALAPPDATA%\PokerLens\profiles\recognition.json`；軟體更新保留此檔與既有使用者資料。主畫面繼續顯示行動建議、下注金額與底池比例、勝率和平手率。

## 啟動

正式版使用者請先到 https://github.com/mgm9453-debug/PokerLens/releases/latest 下載安裝程式，安裝後使用桌面捷徑啟動。正式版無須安裝開發環境。下述命令檔僅供開發端使用；發布與更新方式見 `docs/日常發布與自動更新.md`。

雙擊「啟動.cmd」，或在檔案總管中對「啟動.ps1」選擇使用命令殼執行。
目前專案已備妥獨立環境；搬到其他電腦時，啟動腳本會使用已安裝的三點一四版直譯器建立環境並安裝依賴。第一次需網路連線。

## 使用流程

**辨識前必要設定：請在牌局程式的外觀／牌背設定中，把牌背改成綠色。** 目前持牌人數辨識以綠色牌背為準；其他顏色可能無法確認對手是否仍有手牌，導致行動建議等待資料。

「綠色」指對手蓋牌的背面，不是牌桌背景、正面花色或分析器的牌型矩陣。切換後等待新畫面；底牌與金額也必須清楚可讀。

先開啟牌局，再雙擊「啟動.cmd」。分析器會自動追蹤最前面的牌桌並移到螢幕右側。自動辨識改用指定視窗的圖形內容擷取，其他視窗蓋住牌桌時仍可讀取；請保持牌桌開啟且不要最小化。來源停止更新、黑畫面或牌面／金額未確認時仍會暫停分析。停止自動辨識後可使用下方手動流程。

主畫面持續顯示底池、跟注差額、自身籌碼、各座位下注、持牌人數、獨贏機率、含平手分池權益，以及跟注或棄牌的數學參考。可過牌時另顯示半池下注試算，並標明模型假設；這不是經過完整多人策略評估的最佳加注額。
分析框改用白話說明，例如「目前較適合：跟注八百」「大約有百分之五十八機會贏」「現在可能贏你的牌」。權益、期望值與多人範圍限制移到詳細資料；建議仍依原本計算，並非保證勝出。

「底牌已確認」區域直接顯示讀到的底牌與公共牌。金額或持牌人數尚未確認時，牌面仍獨立顯示；牌面本身不可靠或擷取暫停則改為等待文字，避免沿用舊牌。
底牌使用牌桌專用五十二牌校準，獨立連續三幀確認。公共牌讀取不完整時，已確認的底牌仍會顯示，並標示公共牌正在確認；勝率待完整資料可靠後更新。

辨識連續三幀確認；先使用兩千次模擬提供快速估算，再背景增加到一萬及五萬次。只改金額時會重用相同牌面與對手範圍的權益，立即更新底池賠率及期望值。自身已棄牌時仍顯示牌桌資訊，不產生自身勝率。

主面板自動列出能擊敗你的牌型。翻牌、轉牌與河牌比較當前公共牌，包括同牌型但點數或踢腳更高；翻牌前顯示模擬觀察到的終局擊敗牌型，並非完整可能清單。各對手範圍分別列舉，未驗證多人同時可行，牌型清單不是出現機率。獨贏機率與含平手分池權益分開顯示。

持牌辨識請使用已校準的綠色牌背。金額請使用籌碼數字顯示；未校準的佈局或字型可能需要另外調整。對手範圍預設標準，未辨識到的對手籌碼明確保持未知。原生文字辨識沒有機率信心值，本程式採多幀一致、背景與籌碼證據及金額一致性檢查；牌面分數是字形匹配指標。

1. 點左側底牌或公共牌，從牌面選單挑選。已使用的牌會變灰，避免重複；要移除單張牌，點它再按「移除此牌」。翻牌前公共牌留空，之後由左至右選三、四或五張。
2. 填「目前底池」「需要跟注」「有效籌碼」，設定仍在牌局的對手人數。對手範圍可先保留標準預設。
3. 按「分析」，右側會顯示自身權益、跟注所需勝率、牌型提升補牌與跟注期望值。改牌或金額後，再按一次分析即可。
4. 「清空」開始重新輸入；「載入示範」可快速體驗。清空不刪除歷史。尚未按分析的變更不會繼續顯示舊結果。

## 進階操作

勾選主畫面底部的「進階設定」才會顯示以下功能；一般分析不需要使用。

- 螢幕擷取或虛擬攝影機來源：螢幕編號一為主要螢幕，零為所有螢幕；虛擬攝影機通常從零開始，需先在直播擷取軟體啟動。
- 區域設定：選擇牌桌、底牌、公共牌、底池或玩家，再於畫面拖曳矩形，可儲存及載入設定。
- 完整資料：在牌局資料頁編輯所有狀態欄位並套用，包含玩家、座位、位置、動作、下注、籌碼、盲注及底牌。簡易表單會同步顯示；對手人數不變時會保留進階玩家資料。
- 自訂範圍：在對手範圍頁設定、套用、儲存或載入。不同對手的個別範圍可透過完整資料設定。
- 浮窗：勾選後可拖動、調整大小，並設定透明度及置頂。
- 歷史：點選事件時，左側牌面與金額、右側分析會一起回放；按「返回目前牌局」回到目前資料。
- 詳細計算：主畫面「查看詳細數據與下注情境」可展開平手機率、籌碼底池比與下注表格。

## 資料欄位

程式碼形式的欄位名稱保留識別字；值與介面提示使用中文。

| 欄位 | 意義 |
| --- | --- |
| `hero_cards` | 自身兩張底牌，例如 `["As", "Ks"]` |
| `community_cards` | 公共牌，可為零、三、四或五張 |
| `hero_seat` | 自身玩家座位 |
| `pot` | 目前底池，已包含對手下注 |
| `call_amount` | 自身需要新增投入的跟注額 |
| `hero_stack`、`effective_stack` | 自身剩餘籌碼與有效籌碼 |
| `small_blind`、`big_blind` | 小盲及大盲 |
| `dealer_position` | 莊家座位 |
| `players` | 玩家列表 |
| `current_bet`、`total_invested` | 該街下注與本手累計投入 |
| `confidence` | 欄位信心字典，例如 `{"pot": 0.9}`；低於零點八五不接受 |
| `ranges` | 對手座位到範圍的對應 |
| `hand_id` | 牌局識別，開新手時更換 |
| `street` | 街次；修改公共牌時設為空字串，由程式推導 |
| `showdown`、`hand_complete` | 明確攤牌／完成事件 |

牌碼使用二至九、十、傑克、皇后、國王、王牌的程式表示 `23456789TJQKA`，花色為 `s h d c`。同花／異花範圍標記使用 `s`／`o`，例如 `AKs`、`AKo`；`AK` 包含兩者。

## 數學定義

自身權益包含平手時分得的份額；對手權益是所有對手份額總和。所需勝率＝跟注額／（底池＋跟注額）。跟注期望值＝自身權益×（底池＋跟注額）－跟注額。

補牌數只計算下一張牌能提升自身牌型類別的張數，不代表所有補牌都能打贏對手。下注情境假設一位對手跟注，使用所填棄牌率；未建模未來下注、抽水、邊池與多人分池策略。多對手勝率適用所有玩家共同爭取同一底池的分析。

改變模擬次數或亂數種子會重新分析，固定資料、範圍、次數和種子可重現結果。模擬在背景執行，結果依版本與計算序號檢查，過時結果不覆蓋新資料。

## 開發驗證

在專案根目錄使用已準備環境：

```powershell
.\work\venv\Scripts\python.exe -m pytest outputs\poker_live_analyzer\tests -q
.\work\venv\Scripts\python.exe outputs\poker_live_analyzer\app.py --smoke-test
```

第二個命令驗證首次計算、狀態變更重算、未變更略過，並產生介面預覽與驗證結果。正式設定與歷史存於 `%LOCALAPPDATA%\PokerLens`，測試紀錄使用獨立資料目錄。

玩家精確位置、動作順序、邊池、最小合法加注及完整多人策略仍未自動建模。程式不包含遊戲操作或自動下注。
