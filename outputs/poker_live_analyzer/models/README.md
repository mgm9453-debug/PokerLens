# 辨識模型

點數與花色改用目前牌桌的完整五十二張靜態牌面圖集校準，包含三百一十二個點數及八百一十六個花色模板。一般字型模板已替換；各尺寸、角度與半像素位移在訓練時擴增。花色高度十二至二十八像素逐像素校準，避免縮小後漏讀十五像素黑桃。
花色包含符號本體及含底部小柄的字形。上半部輪廓有較高比對權重，以區分小黑桃與梅花；點數和花色均保留原接受分數與候選差距門檻。傾斜十點數的兩筆畫外接矩形可輕微重疊。
可用 training/train_templates.py 由 visible_card_faces.npz 重建，training_manifest.json 記錄來源雜湊與條件。訓練素材僅為本機靜態可見牌面，不讀協定或即時暗牌。
樣板分數是字形相似度，並非經過校準的分類機率。目前只驗證此八人桌樣式的部分牌面；不同字型、縮放與動畫仍可能暫停辨識。
文字由本機原生辨識讀取；不需要下載大型深度學習模型，也不會上傳牌局畫面。
