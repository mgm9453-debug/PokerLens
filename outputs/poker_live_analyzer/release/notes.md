# PokerLens 1.0.16

- 移除即時主畫面的分析說明框，保留背景分析。
- 上一筆結果改為完整分行卡片，明確標示舊資料與時間，行動、勝率與平手使用不同顏色；歷史金額標示為當時下注與當時底池。
- 相同牌局更新時不先清空顯示；行動或下注內容改變時短暫亮框提醒。牌局變更或資料逾期時，舊結果只保留在歷史卡片。
- 目前下注資料不足時顯示具體原因；完整牌型矩陣在允許的最小視窗中仍可顯示。
- 校準流程簡化為「檢查讀取問題 → 選擇問題並框選 → 確定」。正常位置不顯示綠框，保留自動定位。
- 固定位置修正已接入即時辨識，儲存位置與實際讀值驗證分開；已連續確認沒有持牌且沒有下注的座位，不因缺少籌碼數字而要求校準。
- 即時分析先提供短時間抽樣估算，再於背景提高精度；完整分析與勝率預覽避免重複計算相同牌局，背景精算定期讓出運算時間。
- 金額變動時沿用牌面、持牌對手與設定範圍完全相符的勝率快取；牌面或持牌對手改變時重新估算。
- 保留資料新鮮度、樣本數及跟注收益邊界檢查；關鍵資料未確認時不猜下注金額。

操作提醒：WPT 必須使用綠色牌背與籌碼金額顯示。估算依設定的對手範圍計算，不保證獲利；實際牌局辨識仍受畫面與動畫影響。
