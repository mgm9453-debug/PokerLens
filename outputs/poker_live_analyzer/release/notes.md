# PokerLens 1.0.5

- 修正收合後重複開啟，錯誤顯示另一個啟動或更新程序正在處理；改由程式連線喚回主視窗並確認回應。
- 手動收合後保留懸浮模式，自動靠邊排版不再切換視窗；懸浮窗保持在螢幕可見範圍內。
- 收合與喚回動作加入時間紀錄，改善背景錯誤紀錄的初始化。
- 主視窗真正關閉時，在背景工作與資料庫清理完成後退出程式，避免殘留程序持續占用更新鎖。

- 修正空下注區的微小桌布紋理與頭像側邊造成辨識卡住。
- 金額筆畫被裁切時重新讀取完整區域，避免四位數下注漏掉首位。
- 跟注數字出現千分位誤讀時，重新辨識並與桌上下注差額核對；不直接猜測或改寫金額。
- 保留已完成的勝率估算提示，金額確認後自動恢復行動建議。
- 保留黑金介面、固定座位金額辨識、綠色牌背持牌辨識，以及使用者設定與歷史紀錄。

畫面辨識與勝率依可讀取資料及假設估算，不代表保證結果。
