# PokerLens 1.0.10

- 新增手動框選與固定位置辨識，可在設定中校準底牌、公共牌、底池、跟注金額與各座位區域，驗證後儲存。
- 改善六人與八人牌桌、綠色牌背與木紋牌桌的金額辨識，保留完整數字。
- 分開確認核心金額與各座位下注，減少尚未穩定的座位讀值阻擋分析；確認後的金額矛盾仍會暫停建議。
- 使用實際行動按鈕確認是否輪到自己，按鈕消失或資料過期時撤回舊建議。
- 同一張擷取畫面不再重複累積確認次數，避免把停滯畫面當成新資料。
- 跟注收益接近邊界時，改以底池與跟注金額的比例顯示保守提示。
- 資料失效時清除舊牌型比較顏色，保留完整矩陣與固定版面。
- 改善牌桌尺寸變動與同步發牌期間的辨識處理。

更新會保留使用者設定、辨識校準與歷史資料。此版尚未完成其餘決策優化項目；下注建議仍取決於可確認的牌局資料。
