# 底牌校準驗證

後續四張公共牌回歸：使用者截圖的黑桃皇后在縮小花色高度十五像素時被拒絕。花色校準改為十二至二十八像素逐像素，並加強上半部輪廓權重，保留接受分數與候選差距門檻。相同截圖已正確讀出方塊四、方塊七底牌及紅心四、梅花九、黑桃三、黑桃皇后四張公共牌；完整四百零四項測試通過，約二十五點八七秒。截图顯示的遮擋暫停另外屬擷取保護；當下現場重新檢查已無重疊遮擋視窗，不能據此斷定當時為誤判。

本次只改善自身底牌讀取：替換一般字型模板為牌桌的五十二張標準靜態牌面校準；修正花色含柄與不含柄的差異、小黑桃與梅花的輪廓比對，以及傾斜十點數的兩筆畫拆開問題。底牌獨立三幀確認，公共牌不完整、座位或金額不可靠不再阻擋底牌顯示；完整勝率仍要求必要資料確認。

## 驗證結果

完整專案四百零三項測試通過，約二十點〇六秒；原始碼編譯與依賴相容性檢查通過。新版已實際重新啟動且有回應。

開發驗證：五十二牌乘四組尺寸、角度、遮住下段與輕微模糊，二百零八組完整兩張底牌全數正確，無錯誤接受。另五十二牌乘兩種整桌縮放，共一百零四組全數正確。牌背、無字白牌與重複牌另有拒絕測試。

凍結模型後的另一組保留條件：寬七十四、七十八、八十二、八十六像素；角度負九點五、負六點五、二點五、六點五度，使用不同位置及模糊條件。二百零八組全部正確，無拒絕與錯誤接受。單幀牌面辨識中位數二十五點三三毫秒，百分之九十五分位三十三點一九毫秒，僅為本機樣本測量。

舊模板沿用新擷取流程的對照：相同開發集二百零八組中，一百一十六組正確，九十二組拒絕，無錯誤接受。此對照只比較模板與花色評分，不代表舊版完整流程的實機成功率。

實際畫面：最新縮小至九百一十六乘六百四十九的牌桌，正確認出紅心九、紅心八底牌與黑桃王牌、紅心二、梅花皇后公共牌，約二十五點四毫秒。該截圖未加入模板訓練，已去除玩家名稱後加入回歸測試；其他既有匿名實際牌面亦通過。

完整五十二牌的合成素材與訓練源為同一視覺樣式，因此保留條件是渲染變化的驗證，不能當成全部五十二張實機牌已驗證。不同牌面樣式、嚴重遮擋、極小尺寸與發牌動畫仍可能拒絕；本次未修改座位與金額辨識。
