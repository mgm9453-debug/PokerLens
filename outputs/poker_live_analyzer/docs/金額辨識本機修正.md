# 金額辨識本機修正

本輪優先處理不同桌布下的底池、跟注、籌碼與下注文字。只修改本機，未變更版本、未提交、未推送、未發布。

金額辨識先讀原圖，失败時改用不同縮放、灰階與亮度二值化。有效候選不同時拒絕採用，不依桌布色相判斷下注，也不把未知區域當零。底池補充常見金色文字遮罩；固定底池區域失敗後，在牌桌中央較大區域尋找帶有「底池」標籤的文字，避免把玩家籌碼或下注當底池。此定位仍非任意版面、任意字型的完整辨識。

目前即時金額以 BB（大盲數）讀取、計算與顯示，不再換算成籌碼。牌桌需設定為大盲數顯示；小數讀取精度用於核對顯示四捨五入誤差。無法確認單位不轉換，不將字母錯讀自動替換成數字。

已對本機木紋牌桌影格驗證：底池三點五大盲換算四千二百、跟注零點五大盲換算六百、自身十四點三大盲換算一萬七千一百六十。這些是畫面顯示值的換算，不保證等於未四捨五入的原始籌碼。

仍需完成：木紋空下注區判定、各座位大盲字元誤讀、不同桌型版面定位，以及金額缺失時獨立顯示勝率。上述尚未完成，因此不能宣稱全部牌桌金額與完整自動分析已修好。

改動不會熱更新正在執行的舊行程，須重開本機分析器套用，不影響牌局程式。
