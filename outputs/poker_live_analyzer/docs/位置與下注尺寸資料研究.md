# 位置與下注尺寸資料研究

查閱日期：2026年10月3日。本文件是公開資料研究，尚未把求解器策略接入程式。

## 最新公開更新

- 2026年9月15日：翻牌前獎金權益求解，輸入各座籌碼、前注、獎金與賞金，支援多人翻牌前及三人翻牌後的獎金權益分析。來源：https://blog.gtowizard.com/preflop-icm-solving/
- 2026年3月：兩位跟注者的翻牌後研究。所研究的是八人桌、100個大盲、對稱籌碼、前位開池後大小盲跟注的情境；不能泛化為所有多人底池。相比單挑，開池者在該樣本中更常過牌、較少使用大注。來源：https://blog.gtowizard.com/playing-in-position-against-two-callers/
- 2025年6月2日：動態尺寸改進，針對每個決策點比較候選下注尺寸、期望值及移除尺寸的損失，而非所有局面使用同一個比例。來源：https://blog.gtowizard.com/introducing_dynamic_sizing_2/

## 位置與輸入

需要區分前位、中位、莊家右側、莊家、小盲、大盲，並確認翻牌後誰先行動、誰後行動。持牌人數不等於整桌座位人數，也不能用目前持牌人數反推原本位置。

每個策略情境至少包含：牌桌人數、莊家與盲注位置、大盲與前注、每位玩家的籌碼、各街下注歷史、公共牌、對手範圍、剩餘持牌人數、現金桌或錦標賽、獎金與賞金。多人局面需要各座的籌碼，不能僅取一個最大的對手籌碼。

來源：https://help.gtowizard.com/how-to-build-custom-solutions/

## 翻牌前尺寸

開池常以大盲倍數建立候選，而不是固定底池百分比。官方同位置、不同有效籌碼示例使用2、2.1與2.3個大盲等不同尺寸；這些是特定求解情境，不是一張通用表。

來源：https://blog.gtowizard.com/how-stack-sizes-change-your-range/

再加注需要区分有位置與無位置及額外跟注者。官方樹建構文件示例是有位置用原加注三倍、無位置四倍，額外跟注者可增加尺寸。這是樹設定示例，不代表每個位置、牌型、籌碼深度的最優動作。其預設尺寸也明確標為啟發式起點，並非完全最佳化。

來源：https://help.gtowizard.com/how-to-build-custom-solutions/

## 翻牌後底池比例

可比較的候選包括33%、50%、75%、100%、150%及過牌；候選不是建議。實際最佳尺寸與頻率須依位置、各方範圍、牌面、有效籌碼、底池及前序動作求解。同一手牌也可能混合不同動作。

純金額換算示例，假設目前底池6000、尚未有人下注：

| 底池比例 | 投入金額 |
|---|---:|
| 33% | 1980 |
| 50% | 3000 |
| 75% | 4500 |
| 100% | 6000 |
| 150% | 9000 |

超過自身剩餘籌碼的候選需轉為合法全下或刪除，不能超額下注；涉及不同籌碼與邊池時需獨立處理。

## 百分比加注的算法

以目前底池已包含對手下注、尚未包含自己的跟注為基準：先計算跟注後底池，再以比例計算加注增加量。還需投入＝跟注差額＋比例×跟注後底池。加注至＝自身本街已投入＋還需投入。最低合法加注及全下例外必須另行檢查。

例如原底池1000，對手下注500，現在底池1500，自身本街未投入。加注75%：跟注後底池2000，加注增加量1500，還需投入2000，加注至2000。不能直接用目前底池1500乘75%得到1125當成加注至。

來源：https://blog.gtowizard.com/how-to-calculate-raises-in-poker/

## 程式銜接結論

目前程式的勝率模擬與半底池情境試算不是賽局最佳策略求解器。應先補齊位置、盲注、下注歷史與合法加注限制，再匹配相同條件的已求解策略或離線求解結果。

建議每個尺寸都顯示：動作、加注至或下注額、底池比例、還需投入、有效籌碼大盲倍數。策略來源與匹配條件放在詳細資料，資料不齊時不將啟發式數字標為最優。
