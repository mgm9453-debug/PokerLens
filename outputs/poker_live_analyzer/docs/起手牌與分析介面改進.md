# 起手牌與分析介面改進

原本的棄牌文字由跟注期望值正負決定。自動狀態會把每位對手指定為固定的標準手牌範圍；這個範圍偏強，沒有從位置及實際行動推斷。跟注成本公式沒有發現錯誤，但不應把這種模型估算顯示成完整策略。

現在保留真實計算結果，改為顯示跟注成本估算及範圍尚未確認；不為迎合期待調高勝率，也不直接把所有對手改成任意兩張牌。

## 起手牌參考

來源：
- https://www.pokerstars.com/poker/learn/strategies/level-up-your-starting-hand-selection/
- https://www.pokerstars.com/poker/learn/lesson/pre-flop-essentials/

查閱日期：2026年10月3日。

依教學整理為強起手牌、中等與小口袋對子、大點數、同花發展型、較弱起手牌。強牌包含ＡＡ、ＫＫ、ＱＱ、ＪＪ、ＡＫ與同花ＡＱ。其他牌依位置與是否已有人加注條件顯示。這是教學分類，不是完整賽局最佳化策略或錦標賽全下表。

起手牌提示只出現在公共牌尚未開出時。尚未確認行動位置、大盲倍數、加注歷史，因此不給出本手必須加注的金額。已有人大幅加注或籌碼很短時不能直接套用開池建議。

## 機率與牌型圖片

勝率為獨贏機率，綠色32像素；平手機率為紫色32像素。含平手分池的權益仍在詳細資料中。資料失效時同時隱藏數字與牌型圖，不沿用舊結果。

翻牌三張、轉牌四張、河牌五張時，從目前假設的對手範圍列舉能擊敗自身的合法底牌，每種牌型展示一個底牌與最佳五張成牌的小圖。圖中的牌都必須來自對手範例底牌與目前公共牌，不能補未開出的牌。相同牌型但較大點數也會列出。範例不是對手真實持牌、不是所有組合，也不是出現機率。

## 後續優化優先順序

1. 自動確認六人／八人桌配置、莊家位置與仍坐在桌上的玩家，區分有牌人數與座位總數。
2. 分辨盲注、跟注、開池與再加注，追蹤整手行動，據此估計對手範圍。不能只憑當前持牌人數推斷位置。
3. 可靠读取大盲、有效籌碼、合法最小加注，才提供具體下注金額；加入短碼、全下及邊池處理。
4. 錦標賽加入獎金結構、泡沫及獎金權益，避免把籌碼期望值直接當成錦標賽最佳策略。
5. 提供估算的不確定區間及不同範圍的敏感度，分開顯示底牌、公共牌、人數、金額的辨識狀態。
