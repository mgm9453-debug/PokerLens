# 使用者起手牌表

依使用者提供的十三乘十三牌表及確認的顏色定義，翻牌前顯示藍色「可考慮進場」、黃色「看位置與下注」、灰色「不主動進場」。所有一千三百二十六組實際底牌均可查表，底牌順序不影響結果。

這張圖沒有數字期望值、位置、籌碼深度或面對加注的圖例，因此保存為使用者指定的進場規則，不編造牌型期望值。忠實保留圖片中的特殊格子，例如不同花的Ａ八為藍色、Ａ九為灰色、小對子三三與二二為灰色。

主畫面分別顯示牌表進場規則及目前跟注成本估算。藍色不代表可以跟任何金額，黃色不會在位置未知時直接叫使用者進場；灰色不代表必須棄掉可免費看牌的手牌。跟注成本估算仍依牌面、對手範圍與目前金額計算；缺資料先等待確認。翻牌後不再套用起手牌顏色。

即時畫面移除底下舊進階設定入口，日常參數統一從右上「調整設定」調整。停止自動辨識後，手動練習及歷史回放工具仍可使用；舊擷取框選區域沒有接入目前自動辨識。
