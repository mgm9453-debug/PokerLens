# 底牌辨識校準與驗證

目標：優先改善可見底牌的完整讀取與正確性，不增加下注功能。以目前牌桌靜態視覺素材與匿名實際截圖作來源，不讀遊戲協定或不可見底牌。

流程：先量測原模型的五十二牌覆蓋與實際失敗原因，再建立牌桌專用點數和花色樣板。訓練集使用一組尺寸、角度與筆畫變化；驗證使用不同尺寸、角度、插值、模糊及位置，不把模型自帶樣板辨識成功當獨立證據。合成測試與實際截圖分開報告。

驗收：五十二張牌每張均有驗證案例；記錄正確接受、拒絕、錯誤接受、完整兩張底牌成功率、每幀延遲。牌面空白、牌背、遮擋、未成形字形與重複卡牌不能產生假確認。不放寬原匹配門檻掩蓋問題。

獨立驗證未通過或現場尚未覆蓋全部五十二牌時，明確保留限制，不宣稱每張實機牌均正確。即時背景更新、三幀一致及已確認底牌顯示保留。
