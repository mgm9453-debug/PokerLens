# 打包與發布

版本、產品名稱、發布者、更新公鑰與儲存庫均從 `release/product.json` 讀取。請使用 Python 3.14.5，先安裝 `requirements-dev.txt` 與 Inno Setup 6。

```powershell
./scripts/build.ps1 -Python ../../work/venv/Scripts/python.exe
./scripts/publish.ps1 -Python ../../work/venv/Scripts/python.exe -Unsigned
```

建置輸出在 `dist/install-root`；安裝程式與更新資產位於 `dist/release`。根目錄啟動器有自己的執行環境，各主程式版本保存在 `versions/<版本>`。安裝捷徑指向根目錄 `Launcher.exe`。封裝保留字體、模型及預設設定，排除個人資料、訓練資料、測試與日誌。

更新清單採 `manifest.json` 與獨立的 `manifest.sig`；Ed25519 簽署清單原始位元組。元件分成主程式、執行環境、資源三份 ZIP；每份具 SHA256 與大小。檔名包含內容雜湊；提供 `-PreviousManifest` 可讓未變動元件保留既有下載位址。

安裝包附帶執行環境與資源的壓縮快取，增加部分安裝空間，讓首次更新也能沿用未變動元件。快取以已簽章清單中的雜湊重新核驗，無法通過就重新下載。

正式發布須先填寫儲存庫與 Base64 Ed25519 公鑰。CI 私鑰保存在 GitHub Actions 的 `POKERLENS_SIGNING_KEY` Secret，支援 Base64 32 位元組私鑰或 PEM。不得將私鑰加入專案、安裝包或客戶端。未設定金鑰時本機只能產生未簽署資產，更新器不會接受。

本機可用 `scripts/release.ps1 -Python <執行檔路徑>` 一次完成建置、封裝、簽章與驗證。簽章先使用環境變數，否則讀取 `%LOCALAPPDATA%/PokerLensRelease/signing.key`，也可指定 `-SigningKeyFile`。請把此私鑰備份在受保護的位置；不要加入版本控制或傳給使用者。`-UploadDraft` 會上傳草稿，只有同時指定 `-Publish` 才公开發布；未填儲存庫時遠端操作會停止並提示。

在 GitHub 手動執行「建置與發布 PokerLens」工作流程：測試、建置、簽署、驗證全部成功後才建立草稿與上傳資產。預設保留草稿；只有明確勾選公開發布才轉為正式版本。客戶端不需要任何儲存庫權杖。`publish.ps1` 只處理本機資產，不會上傳或公開發布。

解除安裝刪除安裝目錄中的版本與切換狀態；保留 `%LOCALAPPDATA%/PokerLens` 的使用者資料。

更新器會在舊程式完全退出後，先建立 `backups/update-版本-to-版本-識別碼` 備份。只有其中的 `snapshot.json` 存在，才代表資料庫與白名單設定備份完整成功。備份失敗時不切換新版。回復程式版本不會自動覆寫新版資料；目前資料表未改結構，未來任何破壞性資料遷移必須另外設計還原與跨版本相容性。若需人工還原，先關閉所有程式，保留目前資料副本，再核對備份記錄中的雜湊及檔案清單。

開發電腦首次使用遠端發布腳本，需先透過 `gh auth login` 完成帳號登入。這份登入資訊只保存在開發電腦，並不放進客戶端。若原始碼與公開發行檔分開使用兩個儲存庫，工作流程需要具有目標發布權限的 `POKERLENS_RELEASE_TOKEN` 秘密；單一儲存庫可使用工作流程自己的臨時權杖。客戶端更新來源必須能公開讀取。
