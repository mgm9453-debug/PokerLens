# 設定控制台

主畫面右上角點「⚙ 調整設定」。也可雙擊設定控制台.cmd，獨立開啟相同的設定視窗。

介面頁可調整勝率、平手、行動及說明字體大小，牌型圖片大小，籌碼與牌型顯示開關，勝率、平手、跟注、棄牌、過牌、等待確認的文字顏色。

分析頁可調整每100至1000毫秒更新、最終模擬精度一萬／五萬／十萬次、對手範圍緊／標準／寬及下注試算比例25%至150%。會先保留快速估算，再提高到目標精度。更高精度耗時較長。比例為單一對手情境試算，不代表完整賽局最佳策略。

點套用才儲存與生效；點關閉／取消會放棄未套用的變更，不會撤銷之前已套用的設定。恢復預設先填回預設值，仍需按套用。分析參數套用時，舊計算取消並以當前可靠資料重新分析。獨立控制台儲存的設定由分析器每秒讀取。

設定保存在data/control_settings.json。無效值或損壞檔案不覆蓋最後有效的執行中設定。再次啟動會載入已保存設定。

視窗底部顯示視窗內容擷取狀態及目前牌桌。原生視窗內容擷取不依賴桌面上的其他視窗是否遮住牌桌；最小化、黑畫面、尺寸變動或影格停止更新仍須暫停。正常更新只代表擷取到新畫面，牌面、持牌人數及金額仍需各自通過辨識檢查。

沒有提供手動改動合法最小加注、牌局位置或任意抬高勝率的功能。
