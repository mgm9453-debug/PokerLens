# 三種模式本機試用

主視窗上方選擇現金局、一般錦標賽或神秘寶箱，切換後會重算。浮窗同步顯示目前模式與分析限制。

在「調整設定 → 賽制設定」填寫現金局抽水百分比、上限，或寶箱平均金額。抽水上限零代表無上限；輸入單位必須與牌桌底池一致。勾選抽水確認表示此底池適用指定抽水，包括自行確認未翻牌免抽水等例外。

神秘寶箱必須先勾選賞金階段已開始，再確認平均寶箱金額。平均值不是最大獎項，不會自動從寶箱面板辨識。金額目前支援整數。程式重啟、切換賽制或重新開始擷取牌桌時，需重新確認，數值本身保留。

現金局會提供扣抽水後的跟注成本期望值。一般錦標賽提供籌碼成本參考，目前沒有全場獎金結構、全場籌碼與完整行動策略，因此不顯示已完成的獎金價值決策。

神秘寶箱顯示已知籌碼下的覆蓋關係。只有單挑、對手已全下、籌碼與累計投入已確認相符、自己能完全跟注時，才用直接獲勝機率乘以平均宝箱金額估算當手賞金。平手不當作淘汰，多人不推測寶箱歸屬，賞金貨幣不與籌碼相加；尚未計入未來賞金與完整獎金價值。

三種模式共用牌面勝率與原有對手範圍；切換模式不應憑空改變同一範圍的勝率。抽水與賞金設定也不會改寫原有下注情境表，情境仍是未扣抽水的籌碼試算。
