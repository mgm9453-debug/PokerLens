# 懸浮介面

介面中文使用 Noto Sans TC，英文與數字使用 Inter，字體與授權文件隨程式置於 assets/fonts，不需要安裝到系統。主畫面採深藍細框面板，預設寬一千一百、高八百二十；縮窄時分析資訊會改為上下排列，懸浮窗保持小尺寸。

主畫面右上「收合到懸浮窗」會隱藏主畫面，改顯示置頂小窗。小窗保留目前行動提示、勝率、平手、底池與跟注比例資訊，不再設置「展開／收合」按鈕。「開啟視窗」會恢復完整介面並隱藏浮窗。按住標題附近空白區拖動可移動位置。

此處收合不會停止背景辨識。需停止時返回主視窗，按「停止自動辨識」。程式關閉時浮窗一併關閉。

行動、勝率與跟注成本置於上方。深藍底搭配青綠、紫色和橙色，沿用使用者參考圖的配色方向，沒有複製側欄與大量圖表。手牌與公共牌使用原有牌圖渲染；對手底牌範例不是已讀到的真實手牌。

跟注尺寸是需補金額，占目前底池的比例另列。資料可靠且成本估算為正時提供跟注參考；對手範圍仍是假設。沒有完整位置、加注歷史與合法尺寸時，不會產生主動下注或加注的策略金額。仍可於詳細資料查看數學情境。

金額不一致、底牌不清楚、擷取失效或停止辨識時，浮窗會清除舊金額與勝率，顯示確認狀態。

本次使用已隔離的示範資料檢查主畫面、展開與收合版面，並以測試確認切換、返回主視窗和擷取失效清除。示範截圖不代表即時牌局。
