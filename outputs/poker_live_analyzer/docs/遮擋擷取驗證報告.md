# 被遮擋的牌桌內容擷取

完整四百一十項測試通過，約十九點〇三秒；原始碼編譯與依賴相容性檢查通過。新版已啟動，找到牌桌後自動使用視窗內容擷取。

自動流程從桌面截圖改為指定視窗的原生圖形內容擷取，依視窗控制代碼鎖定來源。保留程式身分、視窗存在、最小化檢查，但不再以桌面上其他視窗的重疊拒絕來源。手動螢幕預覽仍使用原螢幕擷取。

原生影格在回呼中複製，避免借用記憶體失效；約每秒十二幀複製上限。影格時間戳必須前進，超過兩秒未更新、黑畫面、空白、關閉或尺寸不符均拒絕舊資料。停止與重啟使用工作階段序號隔離遲到回呼。視窗尺寸變動時等候新尺寸，未縮放或猜測內容。

本機實際驗證：目前同一遊戲程式的體育視窗被自身建立的洋紅色測試視窗覆蓋，舊桌面擷取拒絕遮擋，新來源仍讀到一千三百七十二乘九百五十六的原始內容；覆蓋色占比為零，來源標頭像素差為零，原生影格時間戳持續前進。測試覆蓋視窗完成後已關閉。當時没有開啟撲克牌桌，因此不是已完成牌桌下注／勝率的遮擋現場驗證。

此電腦不支援停用擷取邊框的系統選項，實作保留作業系統預設值，避免啟動失敗。使用 windows-capture 二點〇點一，相關介面見[套件官方文件](https://github.com/NiiightmareXD/windows-capture/tree/main/windows-capture-python)。
