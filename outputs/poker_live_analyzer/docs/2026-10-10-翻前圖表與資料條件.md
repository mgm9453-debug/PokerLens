# 翻前位置圖表：本機第一階段

本階段已接入莊家徽章、當手在座名單、位置、盲注與矩陣呈現。圖表不等候勝率模擬。翻前灰底白字，自己的底牌有金框；策略紅色加注、綠色跟注、深藍黑棄牌、褐金過牌，可在「調整設定 → 翻前圖表配色」修改。翻後保留原有能贏自己的手牌比較。

辨識器先確認內圈小圓徽章，再比對莊家範本或徽章文字；至少兩次一致才確認。頭像不參與莊家判定。每手鎖定完整在座名單，已棄牌的人不從位置排序移除。無法讀取不等於空位。新手牌、擷取錯誤與等待發牌會清除位置確認。

## 還沒有正式 GTO 範圍

這不是完整 GTO 求解器。本次未收錄未核實的第三方策略，也不會把六人現金局表套到 WPT 錦標賽。目前「無對應範圍」是預期狀態。前注形式、收益模型、完整下注歷史與正式求解資料尚需接入；面對再加注與多方底池未確認時，不猜測動作。

現有 GTO 候選網址：
- https://grindgto.com/range ：頁面標示六人現金局，並非 WPT 錦標賽。
- https://github.com/jensbaagaard/poker-practice/blob/main/data/openSourcePokerData/README.md ：文件記錄從其他應用程式內嵌資料擷取。原始資料再散布授權與求解來源未核實，未收錄。

## 未來正式資料格式

位置圖表使用 `%LOCALAPPDATA%\PokerLens\ranges\mtt-preflop.json`，為 JSON 清單。這個檔案屬於使用者資料，更新不覆寫。每筆資料須包含：

| 欄位 | 用途 |
|---|---|
| format | 固定 MTT |
| players | 實際在座人數 |
| stack_bb | 該解的有效起始籌碼 |
| ante_bb、ante_type | 前注量與形式：無前注、大盲前注或每人前注 |
| payout_model | 籌碼收益或獎金收益模型 |
| position、opponent_position | 自身及對手位置 |
| scenario | 未開池、面對加注、再加注、四次下注、跟入或大盲選項 |
| open_bb | 原始開池尺寸 |
| source、license、solver | 原始來源、可使用授權與求解條件；由維護者核實，欄位文字本身不構成驗證 |
| hands | 各手牌的動作頻率；加注、跟注、棄牌、過牌合計不得超過 1 |

不匹配人數、深度、前注、位置與下注尺寸，就不套用。缺少某手牌不是自動棄牌；頻率不足的剩餘部分保持灰色。混合策略以色塊比例及滑鼠提示完整顯示，不強制選最高頻率動作。

實桌辨識仍需驗證六人與八人版型、空位、新一手與不同縮放；本次成功識別提供截圖的莊家，不等同所有實桌已驗證。

本次只修改本機原始碼，未發布新版本，也未替換桌面已安裝的程式。
