# 正式發布驗證

本機版本：1.0.0。產品名稱 PokerLens，開發者天選之仁。

完整測試：540 項通過。另使用真正安裝程式、更新器與啟動器完成隔離實機驗證，不讀取遊戲牌桌。

- 使用安裝程式安裝並核對應用程式名稱、開發者與版本登錄。
- 移除測試程序環境中的開發環境搜尋路徑後，正式啟動器仍可開啟主程式並正常結束。
- 中文及英文數字字體、模型、辨識執行元件皆可載入。
- 僅變動主程式的測試更新，只讀取一份更新元件；執行環境與資源沿用安裝快取並重新驗證。
- 獨立更新器等待舊程式正常退出，再安裝、備份資料並重新啟動，通過新版健康檢查。
- 模擬無法啟動的新版，可回復並正常啟動舊版。
- 使用者設定雜湊與既有資料庫紀錄保持不變。
- 解除安裝移除程式版本目錄，保留使用者資料。

實機測試升級的版本僅供隔離驗證，不是已對外發布的新版本。沒有宣稱在其他 Windows 電腦或真實網路發行更新上完成驗證。

安裝與簽章更新資產均在 `dist/release`。公開倉庫：`https://github.com/mgm9453-debug/PokerLens`。

目前正式對外上傳尚未完成，瀏覽器擴充功能未允許存取本機檔案。先完成該權限或開發電腦發布工具登入，再上傳所有已驗證的資產並正式發布；只建立公開倉庫不等於已發布可下載的新版本。
