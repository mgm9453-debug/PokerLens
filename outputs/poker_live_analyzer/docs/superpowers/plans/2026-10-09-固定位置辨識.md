# 手動框選與固定位置辨識實作計畫

**目標：** 在設定內校準 WPT 視窗區域，經實際讀取驗證後鎖定，讓相同版型的即時辨識真正使用這些座標。

**架構：** 保留現有辨識器與背景執行緒；新增比例座標校準設定、設定頁與驗證服務。設定存在使用者資料目錄的 `profiles/recognition.json`，不存入程式安裝目錄。沒有鎖定設定時保留既有定位。

**技術：** Python、PySide6、OpenCV、Windows 原生文字辨識與視窗畫面擷取。

## 一、設定資料與契約

- [x] 新增 `capture/calibration.py` 與 `tests/test_calibration_profile.py`。
- [x] 區域識別碼：`hero`、`board`、`pot`、`call_amount`、`hero_stack`，以及 `bet_座位`、`stack_座位`、`back_座位`、選填的 `chips_座位`。
- [x] 提供 `CalibrationProfile(regions, reference_size, seat_layout=8, locked=False, verified_signature='')`；座標使用既有 `Region`。提供 `region_labels()`、`default_regions()`、`CalibrationStore(path)`。
- [x] 修改框選後取消驗證；`mark_verified()` 記錄當前幾何簽章，`lock()` 僅接受簽章相符的設定。以暫存檔取代方式儲存。比例變化超過百分之三時拒絕套用並提示重新校準。
- [x] 先確認新功能測試失敗，再實作；既有舊區域檔格式不改動。
