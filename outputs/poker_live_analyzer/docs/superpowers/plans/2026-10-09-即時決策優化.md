# 即時決策優化

依序處理資料、當手位置與動作、合法尺寸。保留目前主介面與固定區域校準，不加入離線求解、復盤或策略資料庫，本輪不發布。

- [x] 跟注只使用可靠底牌、持牌人數、底池、自身籌碼與跟注成本；其他座位未知下注保留未知。
- [x] 從即時行動按鈕確認自身回合，按鈕消失立即撤回舊建議；勝率可獨立更新。
- [ ] 在記憶體追蹤當手已觀測下注變動，辨識莊家，位置未知時不猜測。
- [ ] 依已觀測的位置與動作調整假設範圍，保持快取隨範圍更新。
- [ ] 只有已確認合法條件時才推薦加注至多少；分開顯示投入額與底池比例。
- [ ] 檢查最低完整加注、短碼全下、加注權與有效籌碼；未知条件不產生加注額。
- [ ] 新功能先跑失敗測試，再實作，最後執行完整測試與顯示驗證。

下注收益仍是有明確假設的估計，不冒充完整多人均衡策略，也不捏造對手詐唬機率。
