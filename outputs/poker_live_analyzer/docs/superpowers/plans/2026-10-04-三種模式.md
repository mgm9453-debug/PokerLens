# 三種模式本機實作計畫

目標：沿用已確認的三種模式設計，僅在本機試用，不變更版本、不提交、不推送、不發布。

架構：共用牌面勝率引擎，另以模式評估模組提供成本與限制。主視窗與設定頁共用持久化設定，切換即取消舊分析並重算，浮窗同步顯示模式。

- [ ] 先驗證設定、抽水、賞金啟動、單挑淘汰與多人限制測試失敗。
- [ ] 新增模式評估；現金抽水由使用者確認，未知時不假造。
- [ ] 錦標賽保留籌碼估算，但不宣稱完整獎金決策；目前無全場籌碼與獎金結構。
- [ ] 寶箱平均金額是貨幣，單挑已全下且能完全跟注時才估算當手賞金；不與籌碼相加。多人、邊池、不完整累計投入、非全下不估算賞金。
- [ ] 主窗、設定頁、浮窗整合並驗證儲存、重啟讀取與重算。
- [ ] 跑相關測試與全套回歸，記錄限制與使用方式。
