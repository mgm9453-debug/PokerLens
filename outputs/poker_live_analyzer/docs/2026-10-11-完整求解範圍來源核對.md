# 完整求解範圍資料核對

使用者要求：只接受完整求解的 GTO 資料，不接受短籌碼近似、啟發式範圍或未核實資料。

## 已核對來源

- GTO Wizard：官方支援複製節點與各動作範圍。尚未取得實際錦標賽資料、完整求解條件及對外再發布授權。複製範圍不代表取得所有節點，也不等於可公開重新打包。
  - https://help.gtowizard.com/ranges-tab/
  - https://gtowizard.com/terms/
- FreeBetRange：官方策略庫表示由 HRC 求解；可按動作匯出文字頻率，完整帳號範圍匯出需相應方案。需取得實際匯出與每套策略的條件；不能將單一動作的節點權重誤認為條件動作頻率。
  - https://help.freebetrange.com/Library/
  - https://help.freebetrange.com/Export/
  - https://help.freebetrange.com/PRO/
- HRC：官方支援匯出全部策略及期望值的 JSON，設定檔 JSON 與策略匯出 JSON 不同。可使用已有、獲准使用的完整求解結果，不要求新增離線求解流程。
  - https://www.holdemresources.net/blog/2023-hrc-v3-release/

## 排除來源

- HoldemMath 多人短籌碼：作者明示單一跟注者近似，只限全下／棄牌，無 ICM；不符合完整求解要求。
  - https://github.com/Julian-cloud-max/holdemmath-data
- poker-practice：範圍來源說明提到從其他程式內嵌資料擷取，原始權利來源尚未核實，不因轉載倉庫標 MIT 就視為已授權。
  - https://raw.githubusercontent.com/jensbaagaard/poker-practice/main/data/openSourcePokerData/README.md
- 一般教學 PDF：未確認所有節點、尺寸與完整頻率前，不視為完整求解資料。

## 本機接入尚需修正的地方

現有 RangeBook 依條件精確匹配；即時 position context 的 ante_bb、ante_type、payout_model 始終為空。未開池時 open_bb 也沒有策略尺寸。即使放入資料檔，仍無法匹配，不能只下載檔案就宣稱功能完成。

現有條件不包含完整行動歷史、各座位籌碼向量、多種加注尺寸與全下獨立動作，尚不足以表示完整策略樹。正式匯入要先以實際資料格式建立節點對應；只允許條件已確認的節點啟用，禁止以最近深度或任意前注替代。

## 實作設計

1. 取得正式平台允許匯出的錦標賽策略及設定，不下載近似表冒充。
2. 匯入時保存位置、人數、各座位深度、前注、收益模型、行動序列、動作尺寸、頻率與求解資訊。
3. 解析節點頻率時明確分辨絕對範圍權重與當前節點條件頻率；未到達節點不任意除以零或補成棄牌。
4. 即時畫面只在條件已確認且節點相符時匹配，無資料保留中性顯示。
5. 矩陣與上方建議使用同一匹配結果；任何未提供的動作尺寸不得由矩陣顏色推算。
6. 在資料授權未確認前只保存於使用者本機，公開倉庫只保留接入程式與文件。
