# 日常發布與自動更新

軟體：PokerLens；開發者：天選之仁。唯一版本來源是 `release/product.json`。

## 第一次給其他人

將 https://github.com/mgm9453-debug/PokerLens/releases/latest 傳给對方。在資產區下載名稱為 `PokerLens-Setup-版本.exe` 的安裝程式。不要下載頁面自動產生的原始碼壓縮檔。

安裝後用桌面捷徑開啟即可，無須安裝 Python，也不用操作命令檔。

## 開發端一次性設定

1. 登入 GitHub 發布工具，並設定本機儲存庫的提交姓名與電子郵件。
2. 到儲存庫的設定 → Secrets and variables → Actions，建立 `POKERLENS_SIGNING_KEY`。內容必須是原本 `%LOCALAPPDATA%\PokerLensRelease\signing.key` 的金鑰，不能重新產生，否則已安装的客戶端會拒絕更新。不要把金鑰傳到對話或提交到原始碼。
3. 原始碼及 `.github/workflows/release.yml` 必須推送到儲存庫。客戶端不用 GitHub 權杖；工作流使用 GitHub 自己提供的臨時權限。

## 以後發布

修改程式後，告訴助手「發布 v1.0.2」，並寫好 `release/notes.md` 的本次更新內容。助手會檢查修改、更新單一版本來源、測試、建置、提交、推送及推送版本標籤。

開發者亦可在開發環境執行 `scripts/發布新版.ps1 -Version 1.0.2 -Python 你的Python完整路徑`。這是開發工具，不是使用者啟動方式。若推送失敗，保留提交，不強制覆寫遠端。

推送標籤後，GitHub Actions 自動測試、打包主程式／啟動器／更新器、編譯安裝程式、產生更新元件、計算雜湊、簽章、建立草稿及上傳資產，全部成功才公開。已存在的版本不覆寫。v1.0.1 已發布，下一次應用新的版本號。

Actions：https://github.com/mgm9453-debug/PokerLens/actions

發布結果：https://github.com/mgm9453-debug/PokerLens/releases

手動執行工作流預設只驗證建置，產物保留在執行結果頁，不建立新版。

## 使用者更新

程式每次啟動自動檢查最新正式發行版，也可以在設定／關於按「檢查更新」。新版提示顯示目前版本、最新版本與 GitHub 更新說明。按「立即更新」後下載元件、驗證大小／SHA-256／清單簽章，安全關閉主程式，由獨立更新器安裝，再重新啟動。

下載失敗可重試。不完整檔案不安裝。新版放在獨立版本目錄，通過健康檢查才確認；失敗回到舊版本。設定與歷史保存在 `%LOCALAPPDATA%\PokerLens`，與程式安裝目錄分開，更新前另備份。程式版本回復不代表任意資料庫結構都能降級；未來若修改資料結構必須另加遷移驗證。

## 錯誤與完整測試

使用者錯誤日誌：`%LOCALAPPDATA%\PokerLens\logs\程式.log` 和 `updates.log`。建置或發布失敗：打開 Actions 的失敗步驟查看記錄。

在獨立測試電腦安裝 v1.0.0，調整一項設定並保存歷史；再開啟軟體，確認提示 v1.0.1 與更新說明。點立即更新，觀察進度與重啟，確認關於顯示 v1.0.1、原設定及歷史仍在。另測試下載時斷網後重試、損壞更新包被拒絕，以及新版啟動失敗回復舊版。不要為了測試而修改正式發布的版本或簽章。

版本公開不等於整套雲端建置已驗證；初次設定後仍須確認至少一次 Actions 實際成功。
