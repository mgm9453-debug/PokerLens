# 公開運算資料整合

來源：https://github.com/poker-yoga/poker-math

固定來源版本：8a68401fb2edffb18865673a47eb500150e2b028。

資料位於 `assets/poker_reference`，保留來源原始資料與授權。資料採 CC0-1.0，來源程式另採 MIT；本次未複製或執行來源程式。

包含 169 種起手牌對隨機單一對手的基準，以及 14,365 組牌型對戰的上三角矩陣。來源記錄每組一百萬次分層蒙地卡羅模擬、種子為 1。這是來源提供的計算規模，並非本程式重新跑一百萬次。

數值是勝出加上一半平手的分池權益，不能拆出獨立勝率或平手率。花色在牌型分類內平均，因此只作參考，不取代指定花色組合的精確運算。

程式將單挑基準顯示在翻牌前的起手牌說明。單一對手且範圍包含完整牌型組合時，按扣除自身底牌後的合法組合數加權提供範圍參考；多人、公共牌已開出或特定花色組合不套用範圍矩陣。

目前牌局勝率、平手率、跟注期望值與行動建議維持原本運算，不因隨機單挑基準高於某個數字就強制進場。使用者藍、黃、灰牌表保持原分類。

資料讀取完全離線、首次載入後快取，並驗證固定 SHA-256、169 種分類、14,365 組值與數值範圍。檔案缺少或損壞時略過參考，保留原分析。

測試包含分類、已知數值、雙向互補、適用條件、原牌表保留、資源失效與獨立蒙地卡羅比對。封裝已包含整個 assets 目錄，所以資料會隨下一個正式版本發布；已發布的 1.0.0 安裝檔沒有被直接覆寫。
