# PokerLens


開發者：天選之仁


Windows 桌面牌桌辨識與分析工具。


[取得最新正式版本](https://github.com/mgm9453-debug/PokerLens/releases/latest)


## 安裝步驟


適用於 Windows 10 22H2／Windows 11 的 64 位元電腦。


1. [下載正式安裝版](https://github.com/mgm9453-debug/PokerLens/releases/download/v1.0.1/PokerLens-Setup-1.0.1.exe)。第一次只需要下載這個安裝檔，其他壓縮檔與驗證檔由更新程式處理。
2. 若舊版 PokerLens 正在執行，先正常關閉；從下載資料夾雙擊安裝檔。
3. 按安裝精靈的提示選擇安裝位置並完成安裝，建議保留預設位置。
4. 完成後，從桌面或開始選單的「PokerLens」捷徑開啟。不需要另外安裝 Python、Node.js，也不需要操作啟動腳本。


## 第一次使用


**開始前，請先在牌局程式的外觀／牌背設定中，將牌背改成綠色。** PokerLens 目前以綠色牌背辨識哪些對手仍有手牌；其他顏色可能造成持牌人數無法確認，讓行動建議停在等待資料。

這裡指的是對手兩張蓋牌的背面顏色，不是牌桌背景、牌面花色或 PokerLens 下方矩陣的顏色。設定選單名稱依牌局程式版本而異，請以實際介面為準。

1. 開啟牌局視窗，保持牌桌正常顯示，不要最小化。
2. 開啟 PokerLens。程式會自動等待並追蹤牌桌；若顯示已停止，按「開始自動辨識」。
3. 等待底牌、公共牌、底池、跟注金額與持牌人數確認後，分析結果會自動更新，不需要反覆按分析按鈕。
4. 先看畫面上方的行動建議、建議金額、底池比例、勝率與平手率，再看可能贏過自己的牌型。
5. 下注仍由你在牌局程式中操作，PokerLens 不會替你按下注按鈕。


## 介面與設定


- 「收合到懸浮窗」：隱藏主視窗，用小型懸浮視窗查看行動建議。
- 懸浮視窗的「開啟視窗」：返回主視窗。
- 「調整設定」：調整介面字體、顏色、顯示內容與分析參數；按「套用」保存。
- 「停止自動辨識」：暫停牌桌讀取。


## 更新方式


程式啟動時會檢查新版，也可到「調整設定」→「關於與更新」按「檢查更新」。有新版時會顯示版本與更新內容，選「立即更新」後會下載、驗證、安裝並重新啟動；選「稍後更新」可繼續使用。


更新前會備份設定與歷史，並保留舊版程式供啟動失敗時回復。網路中斷或驗證失敗時，不安裝未完成的更新，稍後再重試即可。


## 舊版資料與解除安裝


- 從舊啟動版本改用正式版：先安裝正式版，再到「調整設定」→「關於與更新」選「匯入舊版設定與歷史」，選取舊版資料所在資料夾，依提示重新啟動。匯入保留來源；既有非空資料不直接覆寫。
- 個人設定與歷史放在 `%LOCALAPPDATA%\PokerLens`；可以在檔案總管位址列輸入 `%LOCALAPPDATA%\PokerLens` 開啟。關閉程式後，可複製這個資料夾備份。
- 解除安裝：到 Windows「設定」→「應用程式」，找到「PokerLens」並解除安裝。個人設定與歷史會保留。


## 遇到等待確認時


- 牌桌最小化或畫面沒有更新：恢復牌桌視窗，等待新畫面。
- 底牌、金額或持牌人數讀取不完整：保持牌面可見並等待確認；資料未確認時，程式會暫停行動建議。
- 持牌人數一直等待確認：先確認牌局程式已使用綠色牌背，切換後等待新畫面；綠色牌背只協助持牌辨識，底牌與金額仍須清楚可讀。
- 其他視窗蓋住牌桌：視窗內容擷取可讀取仍在更新的牌桌；遊戲本身尚未顯示的牌面，或已最小化而停止更新的內容，無法憑空辨識。
- 查詢更新失敗：確認網路連線，稍後再按「檢查更新」。


勝率與行動建議是依已辨識資料及對手範圍估算，並非保證獲利；是否下注與下注金額請由你自行決定。


本倉庫提供正式安裝檔與更新檔。

開發與自動發布流程請看 [日常發布與自動更新](outputs/poker_live_analyzer/docs/日常發布與自動更新.md)。正式版本透過安裝包及更新資產發送，使用者無須操作原始碼。
